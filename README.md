# PulseGrid — web version

This project only holds the ready-made website of the PulseGrid app, so it can be opened in a browser
(for example on an iPad) at https://s7zqtwxr46-design.github.io/pulsegrid-web-/

**Put it on the home screen:** on an iPad or iPhone, open the link in Safari → tap Share (the square with an
arrow pointing up) → **Add to Home Screen** → Add. PulseGrid then has its own icon and opens full screen, like an app.
On Android: open the link in Chrome → tap the three dots → **Install app**.

The app's source code is kept in a separate private project.
