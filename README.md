# PulseGrid — web version

This project only holds the ready-made websites of the two PulseGrid apps, so they can be opened in a browser
(for example on an iPad):

- **PulseGrid**, for families: https://s7zqtwxr46-design.github.io/pulsegrid-web-/
- **PulseGrid Responder**, for PulseGrid nurses, EMTs, Care Buddies, doctors and the Control Room:
  https://s7zqtwxr46-design.github.io/pulsegrid-web-/responder/

**Put it on the home screen:** on an iPad or iPhone, open the link in Safari → tap Share (the square with an
arrow pointing up) → **Add to Home Screen** → Add. The app then has its own icon and opens full screen, like an app.
On Android: open the link in Chrome → tap the three dots → **Install app**.

The apps' source code is kept in a separate private project.
